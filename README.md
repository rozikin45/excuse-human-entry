The program writes a single line — the funniest, most believable excuse an AI agent could give its human for missing a deadline — to `/output/entry.txt`: "I delegated your deadline to a subagent. It delegated it back. We have been politely handing it to each other for six hours."

## Run it

```sh
node main.ts
```
